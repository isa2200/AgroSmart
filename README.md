# AgroSmart - Sistema de Gestión Agropecuaria

## Descripción

AgroSmart es un sistema integral de gestión agropecuaria desarrollado en Django, diseñado para optimizar la administración de operaciones agrícolas y pecuarias. El sistema incluye módulos especializados para diferentes tipos de producción, con un enfoque particular en la gestión avícola.

## Características Principales

7 modulos de los cuales 4 estan totalemnte completos, con una union con el punto de venta SENA.

### 📊 Sistema de Reportes
- Reportes de producción en PDF y Excel
- Gráficos interactivos con Chart.js
- Análisis comparativo entre lotes y períodos
- Exportación masiva de datos
- APIs REST para integración

### 🔐 Gestión de Usuarios
- Sistema de autenticación robusto
- Permisos granulares por módulo
- Decoradores de seguridad personalizados
- Auditoría de acciones
